# Changelog

## [1.3.0] - 2026-10-30 (Part 3)

### Added & Updated for Part 3 Requirements
- **Lightbox Gallery:** Added a custom JavaScript Lightbox to `products.html` so users can click on cake images to view them full-screen.
- **Inline JavaScript:** Moved the Lightbox and Search Filter scripts directly into `products.html` for immediate execution.
- **Google Forms Integration:** Connected the Enquiry and Contact HTML forms directly to Google Forms (via POST request to Google Form endpoints) so they are fully functional.
- **SEO Optimisation:** Added `<meta name="keywords">` tags to all HTML pages.
- **SEO Files:** Created `robots.txt` and `sitemap.xml`.

### Feedback Fixes from Part 2
- **Fixed Media Queries:** Added `480px` breakpoint and restructured Tablet/Mobile queries to fix responsive issues.
- **Fixed Typography:** Added `rem` scaling for headers on mobile devices to fix typography issues.
- **Improved Changelog Detail:** Expanded this changelog to comprehensively detail every addition and fix.
